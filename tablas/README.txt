CARPETA DE TABLAS - PreflopStudy
================================

Aqui tienes que colocar las imagenes de las tablas preflop
para que el programa las cargue y puedas estudiarlas.

Estructura de carpetas
----------------------
Las carpetas se organizan igual que el visualizador de EducaPoker:

    tablas/
        Cash/2_Universidad/01_BTN.png
        Cash/2_Universidad/02_SB.png
        MTT/2_Universidad/01_BTN.png
        Spin/2_Universidad/01_BTN.png
        2_Universidad/01_BTN.png   <-- si no quieres separar por modalidad

Situaciones (opcional, la primera carpeta):
    Cash, MTT, Spin, 3H, HU, vsMTT

Categorias (la segunda carpeta):
    1_Instituto, 2_Universidad, 3_Diplomado, 4_Doctorado, 5_Summa Cum Laude

Nombre de las imagenes:
    Se ordenan por el numero inicial (01_, 02_, ...).
    Si el nombre contiene BTN, SB o BB se marca con su color de posicion.

COMO EXPORTAR LAS TABLAS DESDE EDUCAPOKER
------------------------------------------
1. Entra en https://rangos.educapoker.com/#/ con tu cuenta.
2. Selecciona el proyecto (Spin / Cash / MTT) y la situacion (3H, HU, ...).
3. En la columna "2_Universidad", haz clic derecho sobre cada imagen y
   elige "Guardar imagen como..." (Save image as...).
4. Guardala en la carpeta correspondiente de esta estructura
   (por ejemplo: tablas\Cash\2_Universidad\01_BTN.png).

Alternativa mas rapida por lote:
   - Haz clic en la imagen para abrirla en grande, clic derecho y
     "Guardar como..." con el nombre que aparezca en pantalla.
   - O usa la extension del navegador "Download All Images" en la
     pagina del visualizador.

FORMATO DE ARCHIVO
------------------
El programa acepta imagenes en formato .png, .jpg, .jpeg, .gif, .webp
y .bmp. Cuanto mas grande y nítida sea la imagen, mejor se veran
los rangos al hacer zoom.

NOTA
----
Si no hay ninguna tabla en la carpeta, el programa carga unas tablas
de DEMO para que puedas probar el modo quiz. Desaparecen cuando
añades tus propias imagenes.
